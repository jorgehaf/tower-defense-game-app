# Roadmap

The work planned for the game, in order. Items are checked as they land on `main`.

## Phase 0: Setup

- [ ] Vite + TypeScript (strict) + Phaser 3
- [ ] ESLint and Prettier
- [ ] Vitest
- [ ] CI with GitHub Actions (lint, test, build)
- [ ] PWA shell with an "under construction" screen

## Phase 1: Playable prototype

- [ ] Map with paths
- [ ] Enemies walking along the paths
- [ ] One tower targeting the most advanced enemy
- [ ] Hull and coins in the HUD
- [ ] Waves read from config

## Phase 2: MVP

- [ ] All MVP towers: Harpoon, Snow Cannon, Lighthouse, Heater
- [ ] All MVP enemies: Penguin, Seal, Walrus, Shark, Orca
- [ ] Resistances
- [ ] Tower upgrades
- [ ] Card picks between waves
- [ ] Boss on wave 10
- [ ] Menu, game over and victory screens
- [ ] Local save

## Phase 3: Mobile

- [ ] Capacitor Android build
- [ ] Safe areas
- [ ] Touch tuning
- [ ] Performance: object pooling, texture atlas
- [ ] Icon and splash

## Phase 4: Depth (ongoing)

- [ ] Breakable ice and dynamic paths
- [ ] Meta-progression
- [ ] New maps, towers, enemies and cards
- [ ] Random events and synergies
- [ ] Sound and music
- [ ] Endless mode
- [ ] Store release
